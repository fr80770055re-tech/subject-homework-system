# 科任作業登記

導師版（typhomework-system）的科任老師版本：不需登入，資料存在本機瀏覽器。

## 使用方式

直接用 Chrome／Edge 開啟 `index.html`（也可放到 GitHub Pages）。

1. 選班級（一忠～六忠）。第一次進入某班會先請你輸入人數。
2. 在班級畫面新增作業，點學生按鈕切換：未交 → 批改中 → 待訂 → 完成。
3. 頂端的班級切換鈕可以直接換班；網址會帶班名（例如 `#三忠`），可以加入書籤。

## 功能

- 作業進度（拖曳排序、改名、全完成、隱藏全過關）
- 出缺勤、每日記事（依日期、各班分開）
- 繳交提醒（產生委婉文字，複製或用 LINE 傳送，會帶入班級與任教科目）
- 列印缺交檢核表（A4 一張四位學生）
- 匯出本班 Excel

## 資料與備份

- 資料存在瀏覽器的 localStorage（`subjectHomework.v1`），**只在這台電腦、這個瀏覽器**。
- 清除瀏覽紀錄、換電腦或使用無痕視窗都會讓資料消失，請定期按「下載備份」。超過 7 天沒備份，頁面上方會出現提醒。
- 換電腦時，在新電腦按「從備份還原」選擇備份檔即可。還原前會自動下載一份目前資料。
- 導師版與科任版的備份格式不同，不能互相還原。
